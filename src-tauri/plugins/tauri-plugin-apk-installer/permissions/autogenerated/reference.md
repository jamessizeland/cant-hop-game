## Default Permission

Default permissions for the APK installer plugin

#### This default permission set includes the following:

- `allow-install-package`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`apk-installer:allow-install-package`

</td>
<td>

Enables the install_package command without any pre-configured scope.

</td>
</tr>

<tr>
<td>

`apk-installer:deny-install-package`

</td>
<td>

Denies the install_package command without any pre-configured scope.

</td>
</tr>
</table>
